# Documentation for `aalibrary`

In the tables below, a parameter whose **Default** is `required` must be given. Some parameters are needed only in some cases (for example the ship and survey names, when the bucket location is built from them); their descriptions start with "Required to ..." or say when they're needed.

    options:
      members:
        - config
        - conversion
        - egress
        - ices_ship_names
        - ingestion
        - metadata
        - queries
        - quick_test
      show_root_heading: false
      show_source: true
